# Licensing & Attribution

## 1. Clean-Room Implementation Notice
VoiceOS-Own is an original, clean-room software implementation developed using standard reverse-engineering interoperability methods.
- **No Proprietary Code Reused:** None of the proprietary JavaScript, TypeScript, or C++ source code from WakoAI Inc.'s VoiceOS distribution was copied or bundled.
- **No Assets Copied:** All icons, styles, fonts, and UI components are independently authored or drawn dynamically using Qt/PySide6 vector primitives.
- **Independent Architecture:** Written in native Python and PySide6, replacing proprietary backend servers (`api.voiceos.com`) with the user's personal Google Gemini API integration.
